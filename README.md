## Featured Projects

### 1) ExtraaLearn — Lead Conversion Classification
Predict which leads will become paid customers and explain the “why” so Sales can prioritize outreach.
- **Highlights:** class-imbalance handling, thresholding for business KPIs (Precision@K vs Recall@K), SHAP/feature importance
- **Stack:** pandas, scikit-learn (DecisionTree, RandomForest), imbalanced-learn, SHAP
- **Results (current run):** RF test **Accuracy 0.84**, **Recall(1) 0.85**, **Precision(1) 0.69**

### 2) Amazon Electronics — Recommendation Systems (KNN & SVD)
Compare popularity, neighborhood CF, and matrix factorization on Amazon ratings; ship top-N and neighbor lookups.
- **Highlights:** User–User / Item–Item (cosine/MSD), SVD MF, GridSearchCV, offline ranking metrics
- **Stack:** pandas, scikit-surprise, scikit-learn, matplotlib
- **Results (test split):** **SVD RMSE 0.8808**, **Precision@10 0.854**, **Recall@10 0.878**, **F1 0.866**

### 3) Unsupervised Learning — Clustering & Dimensionality Reduction
Discover segments and visualize structure for downstream targeting.
- **Highlights:** KMeans (k=4 tried), scaling, silhouette analysis, PCA/t-SNE plots; consumer marketing dataset
- **Stack:** pandas, scikit-learn, matplotlib/seaborn
